# Markdown Resume

This project is a fork of [Oh My CV!](https://github.com/Renovamen/oh-my-cv).

I was using Oh My CV for my resumes. One day I lost a resume to an accidental delete with no confirmation dialog. So I forked it, fixed that, then kept building the features I wanted.


## Features

- Write your resume in Markdown with real-time preview
- Export to PDF in A4 and US Letter sizes
- Auto-pagination like Microsoft Word
- Customize margins, theme color, line height, fonts, and more
- Pick any font from [Google Fonts](https://fonts.google.com/)
- Add icons via [Iconify](https://github.com/iconify/iconify)
- LaTeX math support ([KaTeX](https://github.com/KaTeX/KaTeX))
- Cross-references (great for academic CVs)
- Custom CSS editor
- Multiple resumes
- Works offline (PWA)
- All data stored locally in your browser — no tracking, no ads


## Important

- Use a Chromium-based browser (Chrome, Edge) for best results
- **Back up your data** — click `Save As` regularly, cloud backup isn't available yet
