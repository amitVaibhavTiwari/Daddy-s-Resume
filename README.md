# Daddy's Resume

Free, open-source Markdown resume builder. Write in Markdown, preview as PDF in real time, export with one click. No login, no tracking, no data leaves your browser.

**[daddysresume.amitvaibhavtiwari.dev](https://daddysresume.amitvaibhavtiwari.dev)**


## Features

- Write your resume in Markdown with real-time PDF preview
- Export to PDF in A4 and US Letter sizes
- Auto-pagination, content flows across pages like a word processor
- Fully customizable: margins, theme color, line height, font size, and paragraph spacing
- Pick any font from [Google Fonts](https://fonts.google.com/) or use bundled local fonts
- Add icons inline via [Iconify](https://github.com/iconify/iconify)
- LaTeX math support via [KaTeX](https://github.com/KaTeX/KaTeX)
- Custom CSS editor to override any style per resume
- Multiple resumes, great for targeting different roles
- Three ATS-friendly templates to start from
- Offline support (PWA)
- All data stored locally in your browser, no backend, no tracking, no ads
- Optional Google Drive sync to back up and restore your resumes across devices


## Important

- Use a Chromium-based browser (Chrome, Edge) for best PDF export results

## Why I Built This

I was using Oh My CV! for my resumes when I accidentally lost one without a confirmation prompt. I started improving it to prevent that from happening again, and eventually added the features I wanted for my own resume workflow.
